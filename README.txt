vdesign — PLAIN HTML VERSION

This version uses only HTML, CSS, and JavaScript.
It does not use React, Vite, TypeScript, Java, a backend, or package installation.

To preview:
1. Open this folder in VS Code.
2. Open index.html.
3. Right-click index.html and choose "Open with Live Server".

Main files:
- index.html
- about.html
- services.html
- work.html
- contact.html
- css/style.css
- js/script.js

To change the email address, edit CONTACT_EMAIL at the top of js/script.js.
